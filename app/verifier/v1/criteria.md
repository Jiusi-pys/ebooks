# 验收标准 v1 —— 書房对齐 MarginNote 4

调研来源：MarginNote 4 官方手册（manual.marginnote.com.cn）、官网功能页（marginnote.com/features）、少数派 MN4 上手系列、官方论坛 4.2.x 更新日志（2026-08-30 检索）。

## MN4 功能地图（调研结论）

MN4 的三大模式与关键能力：

1. **文档模式**：导入 PDF/EPUB；摘录（高亮即建卡）；留白/文本框；OCR；文档标签页。
2. **学习模式（学习集）**：学习集 = 主题空间，整合文档 + 脑图 + 复习卡组；文档↔脑图联动视图；卡片盒视图（筛选/搜索/批量编辑/回源）；脑图卡片移动/合并/重组；大纲视图；焦点模式；子脑图；标签与颜色；关键词标题链接（个人字典）。
3. **复习模式**：闪卡（正反面）；FSRS 间隔重复调度（重复/难/中/易 四档）；遮挡挖空 + 回忆模式；复习卡片组；场景记忆回源（跳回书页/脑图位置）。

## 書房现状（改造前）

已有：导入解析、重排阅读、划线/批注/命名、三级引用、AI 伴读、翻译、对比阅读、脑图（目录生成+编辑+折叠）、双链笔记、图谱、文件夹、开放 API + WebHook。

## 本版验收项（必须全部通过）

### A. 卡片体系（数据原子）
- A1 Highlight 支持 `tags: string[]`（弹层可增删标签）。
- A2 Highlight 支持挖空 `cloze: string[]`（弹层可把指定词/短语标记为遮挡项）。
- A3 Highlight 支持复习状态 `review`（加入复习 / 移出复习，删除复习不删卡片）。

### B. 复习模式（间隔重复）
- B1 主导航出现「复习」视图；按书籍分组卡组 + 全部卡组。
- B2 到期队列按 due 时间排序；复习会话正面显示挖空后的题干，翻面显示原文 + 批注。
- B3 四档评分（重复/难/中/易）驱动简化 FSRS/SM-2 调度，写回 due/reps/lapses；再次进入时未到期卡片不出现在队列。
- B4 复习中可「回到原文」定位书摘（场景回源）。
- B5 显示今日已复习数与到期数统计。

### C. 卡片盒视图
- C1 书摘页升级为卡片盒：搜索（文本/批注/名称）、按书籍/标签/颜色/类型筛选。
- C2 卡片可回源定位、可加入复习。

### D. 脑图增强
- D1 焦点模式：聚焦当前分支，只显示该节点及下级，可退出。
- D2 大纲视图：脑图可切换为大纲缩进列表，行内可编辑。

### E. 学习集（主题空间）
- E1 可把文件夹视为学习集：学习集视图聚合其书籍、卡片数、脑图、到期复习数，并可一键进入复习/脑图。

### F. 开放 API 扩展
- F1 新增 `review.updated` / `highlight.tagged` 事件类型。
- F2 `/api/v1/highlights` 支持 tags/review 字段读写；新增 `GET /api/v1/review/due` 到期队列。
- F3 新增 mirror 字段或表（不丢已有数据），drizzle schema 与真实库一致。

### G. 工程质量
- G1 `npm run check` 零错误。
- G2 `npm run build` 成功。
- G3 浏览器实测：复习会话完成至少 1 张卡片评分；挖空在正面被遮挡；焦点模式只显示子树；卡片盒筛选生效；学习集聚合数字正确。
- G4 保存新版本（dynamic）。

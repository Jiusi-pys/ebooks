# 书房 iOS

当前更新：1.4.2（build 10），已对照远端默认分支 `main` 的 `40bac54` 验证。阅读时长上传固定服务器路由，分页读取过滤已删除或不匹配的记录，并拒绝重复游标；本次不改变数据格式。安装与验证边界见 [验证记录](docs/verification.md)。

这是独立的 SwiftUI iPhone / iPad App，最低支持 iOS 17。它连接现有 Node 服务器 https://us.jiusi.org，复用服务器书籍、笔记、摘录、复习和 AI 接口，不加载网站 UI。设计采用 iOS 原生导航、系统字体与控件，以及书架、阅读、记录的清晰层次。

## 已实现

- 原生书架、封面、目录、离线下载；按可用屏幕和字号分页，支持滑动、点击左右翻页与菜单自动隐藏。
- 书内脚注：点击编号在原文旁打开注释浮窗，内容可滚动、复制，关闭后继续原位置阅读；联网时自动补齐正文未变化的旧离线章节脚注。
- 统一学习卡片：跨段精确选择、原文高亮回显、来源回跳、标题、颜色、标签、批注、关联笔记、挖空和问答记录。UTF-16 位置与网页兼容。
- 学习集可使用“申论素材”或“论文研究”模板；iPad 宽窗口提供文档与卡片／脑图并列，窄窗口切换阅读与整理。
- 原生脑图与大纲：添加、移动、折叠、删除节点，拖入已有卡片；引用同一张卡片，支持跨书观点关联。
- PDF 从“文件”导入并先落本机，再上传原文件；PDFKit 支持文字高亮、区域摘录、搜索、缩略图、来源定位、按页 OCR 校正、双文档对照和带批注导出。
- PencilKit 单层手写，Pencil 书写、手指浏览，支持橡皮和撤销／重做。手写以独立附件保存，原文件保持可恢复。
- 卡片、笔记、学习集、脑图、复习评分和手写先落盘，联网后复用 v2 增量同步、操作 ID 和回执。按服务器与账户隔离；并发修改保留双方供选择。
- 按学习集复习、挖空编辑、原文遮挡与复习记录，调度与当前网页四档算法一致，不称为完整 FSRS。
- AI 问答显示设备或服务器模型来源，确认后可存为批注／卡片／可编辑脑图草稿。AI 生成仍需可用模型或网络。
- 搜索书籍、卡片、笔记和已缓存章节全文；笔记双链导航；Markdown 导出、含原文件的学习集备份、恢复预览和冲突策略。
- 一个账户可配置多个 HTTPS 地址，验证账户与同步工作区一致后，按请求延迟自动选路，也可手动指定。钥匙串按地址保存限时会话，离线书籍及待同步队列共用；普通用户无需 API key。

## 构建

在 Finder 双击 打开书房Xcode.command，选择 Shufang scheme 和 iPhone / iPad 模拟器，按 ⌘R。项目位于 iCloud 文稿目录时，这个脚本会使用本地 Xcode 工程入口，源码仍取自本仓库。也可运行：

```bash
swift test --package-path ios
xcodebuild -project ~/Library/Developer/Shufang/Shufang.xcodeproj \
  -scheme Shufang -destination 'generic/platform=iOS Simulator' \
  -derivedDataPath /tmp/shufang-ios-derived build
```

真实服务器须使用证书有效的 HTTPS，并升级到支持账户会话访问 `/api/v1` 的版本。Debug 版只额外允许本机回环 HTTP。客户端拒绝 API 重定向，不会把登录会话转发到其他主机。

若 `swift test --package-path ios` 在 iCloud 文稿目录长时间无输出，可把 `Package.swift`、`Shufang/Core` 和 `ShufangTests` 复制到本机临时目录后运行 SwiftPM，并核对复制前后的文件哈希；验证记录采用了此方法。

## 当前边界

全文检索覆盖本机已有的章节；扫描 PDF 使用按页 OCR，不会首次打开就处理整本书。TXT / Markdown 导入限 2 MB；PDF 导入限 256 MB；EPUB / AZW3 原文件导入和原版重排尚未实现。手写首版为单层；无限画布、视频笔记和多种脑图布局不在本轮范围。

应用在运行和回到前台时同步；不保证被系统终止后继续上传。会话过期时保留待同步内容，重新登录后继续。服务器间手写附件传输需要部署本次 `$attachment` 兼容补丁。恢复文件会校验版本、路径和哈希；单独被删除且原书仍存在的手写页目前会明确拒绝恢复，详见 [备份说明](docs/study-backup.md)。

本轮测试范围与尚未完成的真机验收见 [验证记录](docs/verification.md)，不能把模拟器通过视为 Apple Pencil 实物操作已验证。尚未发布 TestFlight / App Store。

接入细节见 [服务器接入说明](docs/server-integration.md)，当前验证见 [验证记录](docs/verification.md)。

账户连接格式升级与恢复见 [连接格式 v2](docs/migrations/002-account-routes.md)。

阅读默认收起两侧栏。iPad 右侧学习功能采用原生悬浮窗，覆盖在正文上方，不挤压正文宽度；支持窗内搜索、卡片详情和返回原文，点击关闭按钮或窗外可收起。文字阅读可在“阅读设置 → 翻页”选择左右分页、上下分页、上下滚动，以及平移、淡入淡出、无动画；本书专用和通用设置分别保存。连续滚动限当前章节，跨章使用分页按钮。PDF 的更多菜单提供上下滚动、左右滚动、双页阅读。

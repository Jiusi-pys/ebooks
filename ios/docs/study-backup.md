# 原生学习资料导出与恢复

## 使用

在「笔记」左上角或学习集菜单打开「导出与备份」。可选择全部学习资料或一个学习集。Markdown 导出包含可读笔记、卡片、标签、问答和来源信息；完整备份用于恢复可编辑的数据及原文件。

备份学习集时会沿脑图来源卡片、文段关联和笔记双链收集依赖。关联到其他书籍时，也会备份其原文，以免恢复后出现无法返回来源的卡片。不会因为另一学习集包含同一本书，就把该学习集所有成员一并纳入。未关联到所选学习集的独立笔记不在该学习集备份中；选择「全部学习资料」可包含这些笔记。

完整备份开始前会补齐尚未下载的书籍和引用附件。下载中断或原文件缺失会终止本次备份，不会生成声称完整的文件。可取消准备过程并重试；已完成的离线下载仍可使用。

## 版本 1 格式

文件扩展名 `.shufangstudy`，UTType 为 `org.shufang.study-backup`，是由普通文件组成的文件包。可以复制、通过系统分享保存到「文件」。

- `manifest.json`：固定格式名 `ShufangStudyBackup`、版本 `1`、导出时间、标题、服务器源地址、账户 ID，以及每个文件的路径、字节数和 SHA-256。
- `study.json`：`StudyRecord` 数组，保留记录 ID、实体类型和原始字段。包含所选书籍、学习卡片、笔记、学习集、脑图、文段关联、复习事件和相关元数据。
- `books/<SHA-256(bookID)>/package.json`：现有 `OfflineBookPackage` 格式，包含书籍描述、章节目录和正文。
- `books/<SHA-256(bookID)>/source.pdf`：下载的原版 PDF，保持原始字节。
- `attachments/<SHA-256>`：记录引用的二进制附件及 JSON blob，包括原始导入文件、手写和预览图。相同 hash 共用一个附件。

附件引用兼容 `$attachment`、`$blob` 和 `sources` 实体的平面 `sha256/size` 字段。所有引用文件必须存在且长度、哈希一致。备份没有登录密码、API key、会话 token、Cookie 或待发送请求头。账户 ID 用于防止误恢复到另一账户。文件内容未加密，应保存在用户选择的存储位置。

单个原文件或附件上限 256 MB；单次备份有效载荷上限 512 MB；清单最多 10,000 个文件。PDF 同时作为离线原文和引用附件时，文件包内可能各保存一份；达到上限可分别备份较小的学习集。当前不提供 ZIP 压缩。

## 校验、预览与恢复

读取时先检查格式版本、文件路径、重复路径、符号链接、长度、SHA-256、重复记录标识、附件引用完整性及离线章节/PDF 完整性。恢复只接受相同服务器源和账户；HTTPS 默认端口、域名大小写和结尾 `/` 按同源处理。

校验通过后预览记录数、原文数、文件数和与本机相同标识的记录数，再由用户选择：

- 保留本机版本：跳过已有记录，只恢复缺失内容。已删除的普通记录以新身份恢复，不撤销同步协议中的删除标记。
- 保留双方副本：为已有学习记录建立新身份并重连引用；仍存在的同一书籍、原文件和页面手写继续使用稳定身份。不会覆盖既有书籍原文。卡片副本拥有独立的复习事件标识，并保留原复习历史。
- 使用备份版本：同标识内容使用备份字段和离线原文；备份中没有的本机记录保留。

本机同一本书原文与备份不同，且用户未选择「使用备份版本」时，恢复会停止，避免卡片位置与正文不匹配。仅缺失 PDF 而章节一致时，可以补回原文件。

恢复前一次性准备不可变的记录列表、按实体类型区分的标识映射和当前数据指纹，再使用同一映射恢复离线原文。已删除书籍或原文件使用成对的新身份，卡片来源、学习集、脑图、文段关联及页面手写随之重连。只重写已定义的引用字段及 `[[笔记ID]]`、唯一标题双链，不替换正文、标签或问答中的同名字符串；双链显示文字保持不变。多篇笔记重名造成的歧义仍保留，用户可用明确的笔记 ID 区分。

全部检查完成后，先恢复离线原文和不可变的内容寻址附件，再通过 `StudyStore` 一次持久化学习记录与同步队列。若准备后其他编辑或同步改变了学习记录，最终提交拒绝覆盖，要求重新预览。队列持久化失败或指纹不一致时回放原来的离线包；若由于存储设备故障导致回放失败，界面明确提示重新下载受影响原文。新写入但尚未引用的附件不会影响已有数据。网络恢复后按现有 v2 同步协议上传；登录失效不会删除本机结果。

## 兼容与升级

这是新功能的第一个备份版本，不覆盖旧离线缓存，也不改变 MySQL 或 IndexedDB schema，不需要服务器数据库迁移。既有 `OfflineBookPackage` 文件不改写。学习工作区使用独立的持久化目录，由学习同步文档定义其版本和恢复方式。

未来格式变更应增加版本号并保留 v1 读取分支；当前客户端遇到未知版本会拒绝恢复，并保留原备份和当前资料。恢复操作是普通同步修改；程序回滚不会撤销已同步内容。大版本升级前应同时保存文件包和服务器既有的数据备份。

## 验证与限制

自动测试位于 `StudyBackupSelectionTests.swift`、`StudyBackupArchiveTests.swift` 和 `StudyRestoreTests.swift`，覆盖跨书来源闭包、循环双链、无关学习集排除、文件包往返、原文件字节保留、篡改、未知版本、重复路径、路径穿越、超大声明、缺失附件/原文、账户隔离，以及同 ID 不同实体类型、双链重连、复习历史复制、删除书籍恢复和提交前数据变化。测试结果须结合本次验证记录，不将测试用例存在视为通过。

恢复前有完整校验和预览；恢复期间不可取消，以确保本机事务完成。若书籍仍存在，但其固定身份的页面手写被单独删除，当前版本会在写入前拒绝整次恢复并显示具体原因；不会跳过手写后宣称完整恢复成功。随已删除书籍一起恢复的手写不受此限制。跨服务器导入、密码加密、归档压缩，以及替代完整服务器备份，不属于此格式的职责。尚未完成真机大文件、低存储、外部云盘文件提供器中断和 Apple Pencil 真实手写的专项验收时，不应宣称这些场景已通过。

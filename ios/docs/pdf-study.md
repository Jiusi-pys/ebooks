# 原生 PDF 学习

`PDFStudyView` 由 PDFKit 展示原文件，PencilKit 提供单层手写，Vision 在设备端逐页识别文字。适配 iPad 并列阅读和 iPhone 窄屏上下对照。

## 已实现

- 优先读取本机导入的原文件和离线书籍；否则使用当前账户的受认证请求获取原文。
- 页面缩略图、异步文内搜索、上一页/下一页、页面内位置恢复。
- 精确文字摘录、拖框区域摘录、颜色与批注。摘录保存为共享 `StudyCard`，再次打开回显高亮；点击高亮进入共享卡片详情，可编辑和回到来源。
- 选中文字后进入“伴读”，问答沿用设备端/服务器策略；保存的卡片、笔记和脑图保留 PDF 页码和矩形来源。
- “识别本页文字”只处理当前页，结果可校正后存为卡片，不会自动处理整本书。
- Apple Pencil 书写，手指浏览；画笔、橡皮、撤销和重做。手写每次修改后短暂合并保存，离开页面、进入后台和退出阅读时立即保存。
- 双 PDF 对照，分别保留阅读位置。默认独立滚动，开启“同步滚动”后主文档带动对照文档；对照侧仍可单独调整对齐位置。
- 导出带高亮和手写的 PDF。导出写入新文件，原文件不被覆盖。

## 坐标与持久化约定

- 与网页 `PdfHighlightAnchor` 对齐：`page` 从 1 开始，矩形为旋转后的 crop box 左上角归一化坐标。`PDFGeometry` 负责 PDFKit 页坐标转换，裁剪越界值，并拒绝无效数值。
- 跨页文字选择在编辑器列出每一页，按来源页分别保存卡片，共用批注；不会将多页文字绑定到单页矩形。伴读按预览的首个来源页回答。
- 手写保存在独立的 `notes` 记录，ID 为 `pdfink.<bookID 的 SHA-256>.<页码>`。`pdfDrawing` 和 `pdfPreview` 使用 `$attachment` 引用二进制文件；原始 PDF 使用现有 `sources` 记录。旧版网页保留未知字段，不将手写误解析为 JSON。
- 手写坐标使用页面未旋转 crop box 的固定 1000 点宽画布；显示和导出分别缩放到页大小。记录按当前服务器及账户隔离。回调捕获打开文档时的存储对象，切换服务器不会把未保存手写写入另一账户。
- 页面绘图随页面离开释放；保存失败时保留待保存绘图并显示错误。两端修改遵循共享同步队列的冲突处理，不无条件覆盖本机未保存笔画。
- 不新增数据库表或数据库迁移。新增字段是现有 v2 记录里的可选字段。

## 已运行验证

- iOS Simulator SDK 编译器对 PDF 控制器、视图及真实 Core 接口执行类型检查通过。
- `PDFGeometryTests` 三项测试通过：裁剪页面的 0/90/180/270/-90/450 度转换往返；与网页左上角坐标一致；无效值、越界矩形处理。
- 本次几何测试也在不依赖 iCloud 项目遍历的隔离 Swift 包执行，3 项通过。完整 App 构建和工作流结果以 `verification.md` 为准。

## 手动验收

测试文件 `/tmp/Shufang-PDF-Study-Fixture.pdf` 包含三页：普通页、旋转 90 度页、带裁剪原点页，含可选中英文字和区域框。临时文件可由 `/tmp/make-shufang-pdf-fixture.swift` 重新生成；二者不是发布依赖。

1. 在隔离测试服务器登录，导入该 PDF。断网、关闭 App、重新打开，确认原文仍可阅读。
2. 每页选中文字后保存摘录，变更颜色与批注，再从卡片回到原文，确认页码、矩形与文字一致。旋转 iPad、缩放、重开后再次检查。
3. 使用框选截取图框，保存并回查；搜索中文及英文；对当前页 OCR，修改一处识别结果后保存。
4. 对选中文字使用伴读，保存一张卡片，确认问答与页来源仍在。
5. 在真实 iPad 上用 Pencil 写字、擦除、撤销、重做；切后台和重启；联网后在第二个同账户客户端检查。模拟器不能替代 Pencil 真机验收。
6. 选择另一本 PDF，对照侧调整位置后开启同步滚动；检查两份文档仍保留各自的起点。
7. 导出 PDF，在独立 PDF 查看器确认所有页面、旋转、裁剪、文字高亮和手写位置，再确认原文件内容没有改变。

## 当前限制

- 不支持密码保护 PDF 的解锁流程。PDF 全文搜索基于原文件文字层；OCR 结果保存为学习卡片，不回写 PDF 文字层。
- 导出将学习高亮和手写呈现在新 PDF 中；手写的可编辑笔画保留在学习资料备份，而不是输出 PDF 的 PencilKit 层。
- Apple Pencil、长 PDF 的内存和性能、旋转/裁剪页面的视觉导出及两台真机并发手写，需要上述实际设备流程验收；类型检查与几何测试不代表这些流程已通过。

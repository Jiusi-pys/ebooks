# Node 功能与原生 iOS 对应表

2026-10-02：原生 SwiftUI／UIKit、PDFKit 和 PencilKit 实现，复用 v1 阅读服务和 v2 数据同步。版本 1.2.0；验证证据与边界见 [verification.md](verification.md)。

| 能力 | iOS 实现 | 边界 |
| --- | --- | --- |
| 书库与导入 | 封面、文件夹、TXT／Markdown、PDF 原文件上传、离线下载 | EPUB／AZW3 原文件导入未做 |
| 文本阅读 | 动态分页、翻页手势、沉浸菜单、字体样式、跨段选区、高亮回显和来源回跳 | 未下载的章节需联网 |
| 学习资料 | 卡片、标签、批注、笔记双链、挖空、问答、学习集 | 沿用 Highlight 身份 |
| 学习工作台 | 文档与卡片／脑图，双文档对照，窄屏适配 | 一种树形布局和大纲 |
| PDF | 搜索、缩略图、文字／区域摘录、位置恢复、按页 OCR 校正、单层手写、带批注导出 | Pencil 实物操作须单独验收 |
| 脑图与关联 | 节点增删移动折叠、卡片拖入、跨文档观点关系 | 高级无限画布暂缓 |
| 复习 | 按集复习、四档评分、挖空编辑、原文遮挡、历史 | 保留当前调度，不冒称完整 FSRS |
| AI | 来源问答、保存批注／卡片／脑图草稿，写入前确认 | 模型可用性独立于离线资料 |
| 检索 | 书籍、卡片、笔记、已缓存章节全文 | 不下载全库来检索；OCR 按页执行 |
| 同步 | 本地原子存储与待同步操作、v2 快照／增量／回执、冲突选择 | 前台与恢复前台触发；退出后保留队列 |
| 输出和恢复 | Markdown、带批注 PDF、含原件的学习集备份及预览恢复 | 支持格式版本 1；详见备份文档 |

账户会话按服务器和账户隔离。机器 API key 留给服务器间同步及 MCP，节点管理不进入普通用户流程。新增可选字段和二进制附件兼容性见 [study-sync.md](study-sync.md)。

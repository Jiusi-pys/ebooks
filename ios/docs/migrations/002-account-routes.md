# 原生连接格式 v2：一个账户、多条链路

适用版本：书房 1.3.0（6）。服务器接口、MySQL、IndexedDB 均未改变；继续要求已支持账户会话与 v2 capabilities 的服务器。每个地址分别登录，必须具有相同 userID 和 workspaceId。节点无需向 App 暴露机器 API key。

## 升级顺序与保留内容

1. 读取旧 `connection.servers.v1` / `connection.selected.v1` 及原地址的钥匙串会话；此时旧版离线目录仍可读取。
2. 用户使用同一账户登录已添加地址。成功验证后写入 `connection.account.v2`，包含格式版本、账户、工作区、固定存储锚点、地址列表和可选手动链路。
3. 首次写入前在 `connection.before-account-v2` 保留旧地址列表和选中地址；重复执行不覆盖此备份。账户密码不保存。
4. 本地存储锚点沿用首次确认的账户地址。更换链路只更换 HTTP 目标和该目标的会话，不重建学习存储，不移动离线文件，不改变阅读位置键或待同步操作 ID。
5. `StudySnapshot` 仍为兼容的版本 1，仅新增可选 `cursorOrigin`。读取旧文件时，先复制为同目录 `workspace.before-account-routes-v2.json`；复制失败则停止该存储写入并报错。旧数据没有此字段时，第一次同步重新获取快照；之后仅跨地址重置游标。未同步操作保留，旧节点较新字段和删除标记不会被滞后副本覆盖。

旧版按其他 URL 单独积累的缓存目录保留原状，不自动合并无法核验来源的数据。当前账户的主目录继续作为唯一活动目录；旧分区若有尚未同步的资料，需要从原版本导出学习备份后，通过现有恢复预览入口导入，避免覆盖冲突版本。

## 恢复

完整备份需包含 App 的 Application Support、偏好设置和原文件；上面的格式备份不等同于完整书库备份。恢复前保留升级后的目录副本。若需要回退连接格式，在测试或维护环境移除 `connection.account.v2` 并从 `connection.before-account-v2` 恢复旧地址设置；旧二进制可忽略可选 cursorOrigin。不要直接覆盖升级后新增的学习成果；先导出学习备份。会话可能过期，恢复后需重新登录。

本变更无数据库回滚或服务器部署要求。测试涵盖账户/工作区隔离、配置编解码、旧快照缺省字段读取、未同步笔记重开保留、链路切换游标隔离、较新字段及删除标记保留、同步事务固定链路、失败写入不自动重放。真实家庭/云节点联调需用户提供家庭 HTTPS 地址。

# 原生 iOS 与服务器接入

iOS App 是 SwiftUI 在线客户端，不加载服务器网页。服务器仍负责 MySQL 数据库、原文件、AI 服务和 v2 工作区同步；手机使用网站账户的签名会话访问 `/api/v1` 和 `/api/v2`。服务器间与 MCP 的 API key 机制保留。没有数据库结构变更。

## 连接

默认服务器为 `https://us.jiusi.org`。用户可添加、选择或移除任意书房服务器地址。所选服务器的用户名和密码只发送到该服务器的 `POST /api/auth/login`；成功后验证 `GET /api/v1/books`，再把限时签名会话存入设备 `WhenUnlockedThisDeviceOnly` 钥匙串。密码不落盘。服务器源地址不得包含用户名、路径、查询或片段。生产版只接受 HTTPS；Debug 版额外允许本机回环 HTTP。所有 API 请求拒绝重定向，避免把会话转发到其他主机。

会话以服务器地址及账户 ID 隔离本机离线包、阅读记录和进度。会话过期、密码变更后重新登录。当前服务器采用单账户书房模型；若未来支持同一节点上的多账户，服务端还需确保书籍和写入按用户隔离。手机不需要了解多服务器之间的同步方式。

会话到期或服务器拒绝旧会话时，当前账户已下载的书籍仍可离线阅读，联网同步则须重新登录。旧版以机器 API key 为作用域的离线包不会自动归入账户作用域；这些文件不会被本次升级删除，但需要在账户登录后重新下载才能从新书架访问。

## 使用的接口

| 功能 | 请求 |
| --- | --- |
| 书架、导入 | GET / POST `/api/v1/books` |
| 目录、章节 | GET `/api/v1/books/:id/chapters`、`/api/v1/books/:id/chapters/:index` |
| 章节进度 | PATCH `/api/v1/books/:id` |
| PDF 原版 | GET `/api/v1/books/:id/source` |
| 摘录与复习状态 | GET / POST `/api/v1/highlights`、PATCH `/api/v1/highlights/:id` |
| 旧版到期队列 | GET `/api/v1/review/due` |
| 笔记 | GET / POST `/api/v1/notes`、GET / PATCH `/api/v1/notes/:id` |
| AI 问答 | POST `/api/v1/ask` |
| 同步能力检测 | GET `/api/v2/capabilities` |
| 跨端阅读记录 | POST `/api/v2/sync/push`、GET `/api/v2/entities?kind=books` |

iOS 自动适配旧版 v1 DTO 与新版 v2 兼容接口。新服务器的复习卡从当前摘录状态计算到期时间；旧版使用 `/review/due`。笔记详情在保存前必须先加载正文，避免列表不含正文时覆盖为空。摘录的偏移遵循 JavaScript UTF-16 单位。TXT / Markdown 导入先按段切片，再经 POST `/books` 创建服务器记录；当前尚未上传源文件。

## 部署核对

按根目录 `app/README.md` 配置数据库、迁移、持久目录及账户登录所需密钥。服务器须部署本版会话中间件，让 `/api/v1/*` 的阅读资源接受签名账户会话；Webhook 管理仍只接受机器 API key，服务器间与 MCP 的机器入口也保留。反向代理应保留登录响应的 `Set-Cookie` 与后续请求的 `Cookie`、`Origin` 头，并提供 HTTPS 直达地址。AI 伴读需要服务器另行配置模型服务。手机问答超时为 240 秒。

客户端可把书籍章节与可用的 PDF 原版下载到本机，离线时只读这些完整副本；它没有离线写入队列、APNs 或常驻 Webhook 接收器。现有服务器 Webhook 用于通知服务端订阅者；它不是手机推送通道。实际发布前要在真机验证签名、连接、读取、写入回读和离线阅读。


## 1.3.0：账户与多地址

多个地址是同一账户的连接入口，必须返回相同 userID 和 v2 workspaceId。App 对用户添加的地址分别登录，不跨源转发 Cookie，不保存密码。自动模式在网络变化、进入前台和前台每 45 秒测量已登录地址的 capabilities 请求耗时，单个探测超时 3 秒，改善不足 20% 或 30 ms 时保持当前链路；所有地址失败时暂停网络请求并保留离线资料。手动指定时不自动降级到其他地址。

同步及分页事务持有链路锁；切换后重新获取快照，不复用别的节点的增量游标。写请求失败不盲目重放，由持久化操作 ID 和既有同步队列处理。地址首次不可达、未登录或会话到期时需在账户页重新登录。家庭电脑需配置系统认可证书的 HTTPS 域名，可由局域网 DNS 将域名解析到家庭电脑；App 不绕过证书校验。

# 在 iPhone 上体验书房

## 在 Mac 模拟器运行

双击本文件夹的 **打开书房Xcode.command**，在 Xcode 选 iPhone 模拟器并按 ⌘R。工程入口位于本机 `~/Library/Developer/Shufang/`，引用的仍是本仓库源码；这可避开 iCloud 文稿目录的工程文件协调问题。

只想看样本数据，可以双击 **启动模拟器体验.command**。它会启动本机样本服务并安装 App。在 Debug 模拟器连接页填写：

- 服务器：`http://127.0.0.1:8787`
- 密钥：`simulator-only`

样本服务退出后数据丢失。连接你的真实书房时，服务器用默认的 `https://us.jiusi.org`，输入服务器 `OPEN_API_KEY`，点“验证并连接”。这个密钥只保存在当前设备钥匙串；不必发给我，也不要写进源码。

## 在 App 中使用

底部是原生 **书架、搜索、学习、笔记、设置**。点书架里的封面进入目录，再点章节阅读。阅读页根据屏幕大小和字号重新分页；左右滑动，或用底部“上一页 / 下一页”按钮翻页。菜单会自动隐藏，轻点正文即可显示。右上角可开目录、调字号与主题、向伴读提问。长按正文段落可摘录批注或翻译。学习页可进入复习、摘录、脑图、文段关联和译文。

在书籍详情点 **下载离线书籍**，等全部章节下载完成并出现绿色“已下载”提示。以后断网仍能从书架进入已下载书籍；PDF 原版只有在服务器提供源文件时才会一并保存。需要释放手机空间时点“移除下载”，不会删除服务器书籍。

书架右上角的 + 可选择 TXT 或 Markdown 文件导入服务器。目前只支持不超过 2 MB 的 UTF-8 / UTF-16 文本；EPUB、PDF 原文件导入和部分高级 Web 功能仍在开发，完整差异见 [功能对应表](docs/full-workspace.md)。

## 安装到自己的 iPhone

真实手机需要你的 Apple 开发团队签名。连接 iPhone，在 Xcode 的 Signing & Capabilities 选择自己的团队，再选择手机运行。账号密码、验证码和设备 Developer Mode 由你本人按 Apple 提示处理。模拟器钥匙串不会自动复制到真机，需要在真机再次输入服务器密钥。

当前版本没有上架 App Store 或 TestFlight；先在真机验证阅读、网络和数据同步。

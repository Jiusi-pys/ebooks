# Reader fonts

The app bundles these unmodified fonts so that Chinese text styles remain
available on iOS devices that do not include Song, Kai, FangSong, or Yuan fonts.
The corresponding OFL licenses are included in this directory and copied into
the app bundle.

| File | Style | Upstream |
| --- | --- | --- |
| `NotoSerifCJKsc-Regular.otf` | Song | https://github.com/notofonts/noto-cjk/tree/main/Serif |
| `LXGWWenKaiLite-Regular.ttf` | Kai | https://github.com/lxgw/LxgwWenKai-Lite |
| `tkFangSong.ttf` | FangSong | https://github.com/LingDong-/tk-fangsong-font |
| `ZCOOLKuaiLe-Regular.ttf` | Yuan | https://github.com/google/fonts/tree/main/ofl/zcoolkuaile |

`tkFangSong` is primarily designed around traditional Chinese characters. Its
missing characters fall back to the system font.

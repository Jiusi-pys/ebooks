# 原生兼容接口 003：本机下载策略

来源为 android 40f84d9 及已有未提交扩展；不改变数据库 schema 或历史迁移。

新增本地键 `download:book:<id>`，false 表示用户主动移除下载。该键只存在既有本地配置表，不进入业务操作、同步或学习资料包。书目、章节同步字段、引用和学习资料保持原身份；移除下载释放原文件缓存，不删除同步业务正文。

只有原文件的大小及哈希已经取得远端上传提交回执，或经过远端下载校验，才记录 `file:remote:<sha256>`。没有回执时拒绝移除，避免删掉未上传的唯一原文件。内容寻址对象仍被其他书籍或附件引用时保留共享对象，并报告实际释放字节数。活动工作区隔离这些凭据以外的本地状态；它们不是认证凭据。

移除先保存禁止自动下载策略，再清理可释放的对象；失败保留元数据。重新下载显式启用策略，再运行现有分块续传。旧客户端忽略本地键仍能读取；回退不会撤销删除的缓存，需联网重新获取。原文件恢复必须以服务器校验后的对象或先前整库备份为依据。

接口为 downloadState / removeDownload / enableDownload，继续使用 ABI 1。原有 sync / bookResource 不改返回结构；主动移除返回 download_removed。同步传输跳过禁止自动下载的原文件，其他学习附件仍正常传输。网络进行中的下载会在完成后复查策略并清理，不允许立即把刚移除的原文件重新作为可用下载。

历史源文件归档在 compatibility-history/003-local-download。无需数据库迁移；必须验证无远端回执、共享哈希、重启、同步后不重新下载、显式重新下载及业务实体不变。旧版本本机配置键可保留；完整数据恢复使用变更前书库与文件快照。

# 原生兼容接口 005：离线并发冲突与条件同步

来源：android / 40f84d9 与 2026-10-10 已验收的未提交实现。固定 iOS 201a87a 对照；本次方案属于用户已确认的完整冲突处理实现，不修改数据库 schema、已发布迁移或 ABI 1。

## 数据与顺序

在既有 SQLite 本地键表新增版本1的 `sync:edit:<摘要>`（首次编辑的原始字段状态和不可变操作 ID）、`sync:conflicts`（双方原始状态、待处理操作、预览版本）、`sync:withdrawn:<操作ID>`（明确放弃原因和决策身份）。这些键不作为业务数据同步或进入学习包。首个本地编辑与其基线、后续编辑与操作列表必须同事务提交；确认处理与新业务操作、原操作的撤回记录必须同事务提交。

Android 开启保护后：查询真实远端当前状态及重复回执→对比首次编辑基线、当前本地修改和远端→持久保存冲突→暂停发送。没有冲突才发送；服务端可选条件 push 在同一核心锁内比较预期状态并提交。重复操作先核验既有内容，回执丢失不能变成新的冲突或重复写入。接收游标不因未完成冲突而推进。用户选择后生成新操作，不重写原历史身份，也不伪造远端回执。

本地提交只包含实际变化的字段及删除字段，保留完整本地实体；不同字段的并发修改可自动合并。自动更新时间不制造冲突。更新/删除、删除/更新、同 ID 新建、字段移除、大正文引用及不透明手写附件均保留两方；当前版本在预览后变化时拒绝旧选择并重新预览。

## 兼容与恢复

服务端新增 `conditionalPush:1` 能力及只读 preflight；push 的条件为可选，现有 Web/iOS/节点调用不变。缺少能力的服务器仍可读取，但 Android 暂停写入同步，不自动回退到无保护的发送。服务器需先升级，再启用新版 Android。Android 既有未记录基线的待发送操作标为旧队列；与远端已有实体相遇时明确确认，不能从当前值猜测历史基线。

Android 应提升 versionCode 防止普通覆盖安装降级。若人工强制安装旧程序，其同步器不会识别撤回记录，因此不得直接写入同步；保留完整原库与文件备份，安装支持本协议的新程序继续，或经预览将学习包恢复到独立工作区。程序回滚不是数据回滚。

历史源归档：`docs/android/compatibility-history/005-offline-conflicts/`，原始字节 SHA-256 不变。发布前另保存独立书库/原文件备份；本地键格式为追加，旧库不删除或重建。失败、取消、断网和认证失效保留原库、待发送与双方附件，重启后继续。已完成决策保留可审计撤回原因；只有有效远端回执或明确撤回才能推进发送游标。

## TDD 验收

先覆盖两端同字段、独立字段、双方同值、删除、字段移除、Unicode、手写引用、陈旧预览、重复回执/丢失回执、重启、取消/失效及服务器切换；验证服务器检查与提交之间没有竞态。再接入原生冲突列表/预览/选择、真实双客户端网络、Android 设备界面和共享回归。实际结果追加到运行报告，未执行项目不得记为通过。

## 删除书籍与文件夹的本机保留

删除标记沿用旧协议不可逆。选择本机或双方副本时，为书籍／文件夹及其当前本地学习依赖创建新身份；重建卡片、笔记、脑图、学习集、关系和复习事件的引用，原文件与附件沿用已校验内容哈希。原实体保持服务器确认的删除状态。复制与撤回仍在同一决策事务提交；稳定偏好键与唯一关系仅提供本机／服务器选择，不生成无意义的重复键。

书籍副本与其sources原文件记录共享新的书籍身份，避免只复制书籍元数据而丢失原文件入口。已通过两端真实网络同步后读取原文件字节的专项测试。2026-10-10实际服务器升级、回退、备份及跨端结果见 [验收记录](../../evidence/android-ios/offline-conflicts-20261010.md)；无schema或历史迁移修改。

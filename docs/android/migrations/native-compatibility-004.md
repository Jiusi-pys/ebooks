# 原生兼容接口 004：不可变复习事件的发送身份

新增恢复与真实跨端验收发现：原生本地事务给 reviews 实体和其创建操作分配了两个身份，而既有 v2 接收契约要求两者一致。修复只影响此版本之后生成的复习创建操作；实体 ID、评分、调度与 createdAt 保持不变，不改变数据库 schema、已发布迁移或接收规则。

新生成 reviews 操作的 operationId 固定为其 entityId；同一操作的重试遵循既有唯一账本，不重新评分。学习备份恢复新工作区、首次合并及复制卡片时，在预览中确定新事件身份，然后使用相同操作身份原子提交。其他业务种类继续使用原有操作身份规则。

旧工作区已经记录的不匹配操作不可改写、伪造回执或标记已同步。发现历史无效事件时保留原书库与操作历史，通过显式确认的学习包恢复到独立工作区重新提交，原历史仍可审计。回退程序不会撤销已发送事件；旧接收节点已经支持同身份规则。历史源归档在 compatibility-history/004-review-operation，配合实际书库与原文件备份恢复。

验证门槛包括本地评分与历史恢复事件发往真实接收核心、重复接收不重复历史、评分状态保持、Android/iOS 网络往返、整体事务失败及跨端现有测试。未经重建的旧无效操作仍属于待处理限制，不宣称自动修复旧书库。

## 已实现

WinUI View/ViewModel 通过 C ABI 调用共享 Rust 用例，Rust 核心不引用视图。
桌面和独立服务使用同一 SQLite、原文件库和业务规则。包含书籍/文件夹管理、
多格式导入、PDF 原版/重排、文本选区与划线、阅读记录、引用笔记和跳回、
原生 Markdown 预览/双链、关联图谱、脑图、学习集、复习队列和译文。

AI 包含配置、DPAPI 密钥、流式问答/翻译、分段全书导读、生成脑图/卡片、
取消、超时、结果校验和保存。提供 OpenAI、DeepSeek、Kimi、MiniMax、Codex CLI 适配。
独立服务包含 REST、MCP HTTP/stdio、PKCE OAuth、Webhook 持久化重试、界面启停、
可选登录启动、端口保存，以及工作区备份/恢复到新目录。
